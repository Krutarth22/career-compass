# Clinical Trial Analysis and Reporting Capstone

## Production Workflow Mirrored
1. Supporting a trial from design through database lock to reporting
2. Producing standards-compliant datasets and validated outputs
3. Performing the unblinded analysis and interpreting it
4. Writing the statistical parts of the study report and a manuscript
5. Responding to reviewer or regulatory questions

## What You'll Build
An end-to-end analysis of a trial using shared trial data (from a data
sharing platform, a published trial's supplement, or a full synthetic
trial generated from your design): the design and analysis plan,
SDTM and ADaM datasets with conformance validation, the full output
package with validation, the primary and secondary analyses with
sensitivity analyses, a clinical study report statistical section, a
manuscript-style results paper following CONSORT, and written
responses to a set of reviewer questions.

## Student-Scope Notes
- Reuse the plan, datasets, and programs from earlier templates,
  adapted to one coherent trial.
- Reviewer questions can come from a mentor or from published
  regulatory review templates.
- The synthetic option must simulate realistic missingness and
  dropout.

## Steps
1. Finalize the trial design and analysis plan for the chosen data,
   and simulate blinded data review decisions (population definitions,
   protocol deviations).
2. Build and validate the SDTM and ADaM datasets with conformance
   checks and define metadata.
3. Program the full output package from a driver script with
   independent validation of key outputs.
4. Run the primary analysis and all planned secondary and sensitivity
   analyses; check assumptions and document.
5. Write the statistical section of the clinical study report with
   results tables and interpretation.
6. Write the CONSORT-compliant manuscript with the flow diagram and
   the required reporting elements.
7. Answer a set of reviewer questions on the analysis with additional
   outputs where needed.
8. Assemble the deliverable package (plan, datasets, programs,
   outputs, report, manuscript, responses) and present the results.

## Extension Ideas
- Add an interim analysis simulation with a data monitoring committee
  report.
- Conduct a subgroup analysis with appropriate interaction testing and
  caveats.
- Produce a plain-language results summary.
- Submit the manuscript to a journal or preprint server if the data
  permit.

## Skills Demonstrated
- Study-level statistical support from design to reporting
- Standards-compliant datasets and validated outputs at scale
- Full analysis with interpretation and sensitivity
- Regulatory-style and manuscript reporting with reviewer responses

## Industry Relevance

Pharmaceutical Companies, Contract Research Organizations, Biotech, Academic Trial Units. Study biostatisticians in these sectors own the analysis from plan to report, and senior interviews ask candidates to walk through a trial they supported end to end. A complete trial package with validated outputs and reviewer responses is the definitive biostatistics portfolio.
