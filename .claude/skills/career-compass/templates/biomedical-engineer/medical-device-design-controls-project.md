# Medical Device Design Controls Project

## Production Workflow Mirrored
1. Capturing user needs and translating them into design inputs
2. Producing design outputs traceable to inputs
3. Managing risk throughout with a risk management file
4. Verifying outputs against inputs and validating against user needs
5. Maintaining a design history file through reviews

## What You'll Build
A design history file for a simple medical device you design and
prototype (a pill organizer with adherence sensing, a custom orthotic
component, a specimen handling tool, a low-cost pulse oximeter probe
holder): user needs from interviews, design inputs with acceptance
criteria, a risk management file per ISO 14971 with hazard analysis
and controls, design outputs (drawings, software, specifications), a
verification test plan and report, a validation with representative
users, design reviews with records, and a traceability matrix linking
everything.

## Student-Scope Notes
- Keep the device simple and non-invasive so you can prototype and
  test it safely.
- The design history file structure should follow the regulation's
  elements and cite them.
- Validation must involve at least three representative users.

## Steps
1. Interview at least three potential users or clinicians and document
   user needs.
2. Write design inputs with measurable acceptance criteria and hold a
   design input review.
3. Perform the risk analysis: hazards, sequences, harms, severity and
   probability, risk controls, and residual risk evaluation.
4. Produce the design outputs: CAD and drawings, any software, and
   specifications, with risk controls implemented and traced.
5. Build the prototype and write the verification plan mapping each
   input to a test.
6. Execute verification and write the report with pass and fail
   results and any design changes.
7. Conduct validation with representative users in simulated use, and
   document results against user needs.
8. Hold the design review, complete the traceability matrix, and
   assemble the design history file with an index.

## Extension Ideas
- Add a usability engineering file with formative evaluations.
- Add software lifecycle documentation for any software.
- Perform a design transfer package to manufacturing.
- Run a design change through the process with impact assessment.

## Skills Demonstrated
- User needs and design input development
- Risk management integrated with design
- Verification and validation planning and execution
- Design history file assembly and traceability

## Industry Relevance

Medical Device Companies, Digital Health Hardware, Contract Design Firms, Hospital Innovation Centers. Design controls are the regulatory backbone of device development in these sectors, and engineers who have produced a complete design history file are immediately useful. A simple device with a full file and traceability is the standard biomedical engineering portfolio piece.
