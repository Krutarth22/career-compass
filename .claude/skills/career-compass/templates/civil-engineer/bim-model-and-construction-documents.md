# BIM Model and Coordinated Construction Documents

## Production Workflow Mirrored
1. Building a structural model in BIM software with proper families and
   levels
2. Coordinating with architectural and MEP models and resolving clashes
3. Generating plans, sections, and details from the model
4. Writing specifications and general notes
5. Issuing a document set with revisions and a transmittal

## What You'll Build
A BIM model of the building from your structural analysis in Revit
(student), Tekla, or an open BIM tool, with structural elements
modeled correctly by level, a simple architectural and MEP context for
coordination, a clash detection run with resolutions, a set of
structural drawings generated from the model (plans, elevations,
sections, typical details), general notes and an outline specification,
and an issued set with a revision.

## Student-Scope Notes
- Student licenses for major BIM tools are free; open-source BIM is
  acceptable.
- The architectural and MEP context can be simple massing and a few
  ducts or pipes that create realistic clashes.
- The drawing set should look like a real issue: title blocks, sheet
  index, north arrows, and key plans.

## Steps
1. Set up the project: levels, grids, and the structural template with
   the right units and view templates.
2. Model the structure: foundations, columns, beams, floors, and the
   lateral system, with correct families and materials.
3. Add a simple architectural and MEP context and run clash detection;
   document each clash and its resolution in the model.
4. Generate framing plans for each level with tags, and foundation
   plans with marks and schedules.
5. Create sections and typical details (a beam-column connection, a
   slab edge, a footing) drawn or detailed from the model.
6. Write the general notes (codes, loads, materials, special
   inspections) and an outline specification for structural sections.
7. Assemble the drawing set with a sheet index and issue it as "for
   review," then make a design change and issue a revision with clouds
   and a transmittal.
8. Write a short note on the model structure, the coordination
   findings, and how the change propagated through the set.

## Extension Ideas
- Link the analysis model to the BIM model and round-trip a change.
- Add quantity takeoff from the model for a cost estimate.
- Produce a 4D sequence for the construction phases.
- Set up a shared model with worksets and a second contributor.

## Skills Demonstrated
- Structural BIM modeling and coordination
- Clash detection and resolution
- Drawing production from a model
- Notes, specifications, and revision control

## Industry Relevance

Architecture and Engineering Firms, Construction Contractors, Infrastructure Owners. BIM proficiency is expected of civil and structural engineers in these sectors, and drawing production from coordinated models is daily work. An issued set with a documented revision and clash resolutions is the artifact firms want to see.
