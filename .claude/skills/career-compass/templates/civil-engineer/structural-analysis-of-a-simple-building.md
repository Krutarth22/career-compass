# Structural Analysis of a Simple Building Frame

## Production Workflow Mirrored
1. Determining loads from the governing code (dead, live, wind, snow,
   seismic)
2. Tracing the load path from roof to foundation
3. Analyzing members by hand and with structural software
4. Checking members against the material design code
5. Producing calculation packages a reviewer can follow

## What You'll Build
A complete structural calculation package for a small one- or two-story
building frame (a steel or timber framed workshop, a small commercial
bay): code-derived loads with references, a load-path diagram, hand
analysis of representative beams, columns, and a lateral system, a
structural analysis model in free software with results correlated to
the hand calculations, member design checks to the applicable code,
and a stamped-style calculation package with a summary.

## Student-Scope Notes
- Use the code applicable to your region (ASCE 7 with AISC or NDS, or
  Eurocodes) and cite clauses.
- Free analysis tools (a student version of a commercial package, or an
  open-source frame analysis tool) are sufficient.
- This is an educational exercise; it is not a sealed design. State
  that on the cover.

## Steps
1. Define the building: geometry, occupancy, location, roof and floor
   construction, and the framing system.
2. Determine design loads from the code: dead, live, roof, snow, wind,
   and seismic as applicable, with clause references and combinations.
3. Draw the load path diagram from roof to foundation for gravity and
   lateral loads.
4. Analyze representative members by hand: a roof beam, a floor beam, a
   column with combined loading, and the lateral system (a braced frame
   or shear wall).
5. Build the analysis model, apply the same loads and combinations, and
   compare reactions, moments, and deflections with the hand analysis.
6. Design and check the members to the material code: strength,
   stability, deflection, and connections at a preliminary level.
7. Size the footings from bearing pressure using an assumed allowable
   value, with the assumption stated.
8. Assemble the calculation package: cover, assumptions, loads, load
   path, analysis, checks, and a summary table of members with
   utilization ratios.

## Extension Ideas
- Add a seismic analysis with a response spectrum.
- Design a moment connection in detail.
- Compare steel and timber framing for the same building.
- Model the second-order effects and compare with the amplified
  first-order method.

## Skills Demonstrated
- Code-based load determination and combinations
- Load path reasoning
- Hand and software structural analysis with correlation
- Member design checks and calculation documentation

## Industry Relevance

Structural Consulting, Building Design Firms, Construction Engineering. Entry-level structural engineers in these sectors spend their days producing calculation packages, and interviewers ask candidates to walk through a load path and a member check. A complete, cited package with hand and software correlation is the direct work sample.
