# Study Data Management Lifecycle Capstone

## Production Workflow Mirrored
1. Managing a study's data from protocol to archive
2. Coordinating build, validation, coding, reconciliation, and lock
3. Handling a protocol amendment mid-study
4. Preparing for and responding to an audit
5. Delivering to statistics and archiving with documentation

## What You'll Build
A complete data management lifecycle for a new synthetic trial run
with simulated sites entering data: the data management plan, the
database build and testing, the validation plan and checks, live data
cleaning with query metrics over several simulated cycles, coding and
reconciliation, a protocol amendment with database migration, an
audit simulation with findings and responses, database lock, transfer
to statistics, and an archive package.

## Student-Scope Notes
- Recruit peers to act as sites entering data with realistic errors;
  or script data entry with seeded errors.
- Reuse the plans and processes from earlier templates on one study.
- The audit should be conducted by someone using a published audit
  checklist.

## Steps
1. Write the protocol synopsis and the data management plan, and build
   and test the database.
2. Implement the validation plan and start data entry with the
   simulated sites.
3. Run at least three cleaning cycles with query issuance, response,
   and metrics reporting.
4. Process a protocol amendment: impact assessment, specification
   changes, database migration with testing, and site communication.
5. Perform coding and reconciliation, and report status.
6. Undergo the audit simulation, receive findings, and write corrective
   action responses with evidence.
7. Execute the database lock with the checklist and transfer data to
   statistics with a transfer document.
8. Archive the study documentation with an index and write a
   retrospective on metrics and lessons.

## Extension Ideas
- Add a risk-based quality management plan with monitoring.
- Add a vendor oversight process for a lab data vendor.
- Produce an inspection-readiness storyboard for data management.
- Run the same study with a second EDC and compare processes.

## Skills Demonstrated
- End-to-end study data management
- Amendment and migration control
- Audit readiness and corrective action
- Lock, transfer, and archival with documentation

## Industry Relevance

Pharmaceutical Companies, Contract Research Organizations, Biotech, Academic Research Organizations. Lead clinical data manager roles in these sectors require having taken a study through its full lifecycle including amendments and audits, and interviews ask for exactly that experience. A complete simulated study with an audit response is the definitive data management portfolio.
