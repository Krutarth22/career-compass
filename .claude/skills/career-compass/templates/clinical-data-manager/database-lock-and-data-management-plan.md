# Data Management Plan and Database Lock

## Production Workflow Mirrored
1. Writing the data management plan governing the study
2. Tracking data cleaning metrics toward lock readiness
3. Running the lock checklist and freezing the database
4. Archiving with audit trails and documentation
5. Handling post-lock changes with control

## What You'll Build
A data management plan for your trial covering roles, systems, data
flow, validation, coding, reconciliation, quality control, and lock
procedures, a cleaning metrics dashboard from EDC exports (open
queries, missing pages, unsigned forms, unresolved discrepancies), a
database lock checklist executed with evidence, a soft lock and hard
lock simulation with a snapshot and audit trail review, an archive
package, and a documented post-lock unlock and change.

## Student-Scope Notes
- Use your database and the exports it produces.
- The lock checklist should follow published industry guidance and
  cite it.
- Simulate the post-lock change realistically (a late safety report)
  and follow the change control end to end.

## Steps
1. Write the data management plan with all required sections and
   references to your specifications and validation plan.
2. Build the cleaning metrics dashboard from EDC exports, with trends
   toward lock readiness targets.
3. Define the lock readiness criteria and the checklist, including
   sign-offs from statistics and medical review.
4. Run the cleaning cycle to readiness: resolve queries, complete
   coding and reconciliation, and document any accepted exceptions.
5. Execute the soft lock: freeze forms, run final listings, and obtain
   sign-offs; record the evidence.
6. Execute the hard lock: take the snapshot, review the audit trail
   for unexpected changes, and archive the datasets and documentation.
7. Process a post-lock change: impact assessment, approvals, unlock,
   change, re-lock, and documentation.
8. Assemble the lock package and write a lessons-learned note.

## Extension Ideas
- Add a risk-based quality management approach with key risk
  indicators.
- Prepare an inspection-readiness binder index for data management.
- Automate the metrics dashboard with a scheduled export.
- Write a database transfer specification to biostatistics.

## Skills Demonstrated
- Data management plan authoring
- Cleaning metrics and lock readiness management
- Lock execution with audit trail review and archival
- Controlled post-lock changes

## Industry Relevance

Pharmaceutical Companies, Contract Research Organizations, Biotech, Academic Trial Units. Database lock is the milestone clinical data managers are accountable for in these sectors, and lead roles require having run one with proper documentation. A lock package with evidence and a controlled post-lock change demonstrates that accountability.
