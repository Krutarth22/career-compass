# Facility Layout and Material Flow Design

## Production Workflow Mirrored
1. Analyzing product flows, volumes, and relationships between areas
2. Generating and evaluating layout alternatives quantitatively
3. Designing material handling and storage
4. Checking safety, ergonomics, and code constraints
5. Producing a layout drawing and an implementation plan

## What You'll Build
A layout design for a real small facility (a makerspace, a small
workshop, a warehouse section, a campus lab, a food service back of
house): a from-to chart and relationship diagram from observed flows,
at least three layout alternatives evaluated by material handling
distance and a weighted relationship score, a material handling and
storage design, a safety and ergonomics check, a scaled CAD layout
drawing of the selected alternative, and an implementation plan with
a phased move.

## Student-Scope Notes
- The facility must be real and its flows observed; use your time
  study data if the same process.
- Systematic layout planning by hand plus a spreadsheet for scoring is
  sufficient; layout software is optional.
- Aisle widths, egress, and ergonomic reach must respect real
  guidelines, cited.

## Steps
1. Document the current layout to scale and the products, volumes,
   and routings that flow through it.
2. Build the from-to chart and the activity relationship chart with
   reasons for each relationship rating.
3. Compute the current material handling distance and score.
4. Generate three alternatives using systematic layout planning, and
   evaluate each on distance, relationship score, and qualitative
   factors.
5. Design material handling (carts, conveyors, shelving) and storage
   (point of use, supermarket, bulk) for the selected alternative.
6. Check the layout for safety and ergonomics: aisles, egress, reach
   and lift zones, and hazard separation, with cited guidelines.
7. Draw the selected layout to scale in CAD with equipment, storage,
   flow paths, and utilities.
8. Write the implementation plan with phases, downtime, costs, and
   risks, and present the layout to the facility's owner.

## Extension Ideas
- Simulate the new layout's flow with your simulation model.
- Optimize the layout with a quadratic assignment heuristic.
- Add a 3D walkthrough model.
- Implement a phase and measure the flow improvement.

## Skills Demonstrated
- Flow analysis and relationship charting
- Layout alternative generation and quantitative evaluation
- Material handling and storage design
- Safety and ergonomic constraint checking and implementation planning

## Industry Relevance

Manufacturing, Distribution Centers, Hospitals, Retail Operations. Layout and flow design is a recurring project for industrial engineers in these sectors, from new facilities to reorganizations. A scaled layout with quantified alternatives and an implementation plan is a work sample employers immediately recognize.
