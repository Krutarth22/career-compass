# Process Flow, PFMEA, and Control Plan for a Part

## Production Workflow Mirrored
1. Defining the manufacturing process flow for a part from its drawing
2. Analyzing failure modes at each step with severity, occurrence, and
   detection
3. Establishing controls, inspection points, and reaction plans
4. Writing work instructions operators can follow
5. Linking the documents so a change in one propagates

## What You'll Build
The core process documentation set for a real part you can make or
observe (a machined bracket, a printed and assembled housing, a
soldered electronics assembly, a woodworking product): a process flow
diagram with operations and inspection points, a PFMEA following the
AIAG-VDA or classic approach with action priorities, a control plan
tied to the drawing's characteristics, work instructions with photos
for two operations, and a traceability matrix among them.

## Student-Scope Notes
- Making the part yourself (even with hobby tools) is best; observing
  a makerspace or a friend's process is acceptable.
- Use the drawing's dimensions and characteristics as the basis for
  what is controlled; if no drawing exists, produce one.
- Keep the PFMEA focused: ten to twenty failure modes with honest
  ratings.

## Steps
1. Obtain or produce the part drawing and identify its critical and
   significant characteristics.
2. Draw the process flow: every operation, transport, inspection, and
   storage, with inputs, outputs, and equipment.
3. Build the PFMEA: for each operation, the failure modes, effects,
   severity, causes, occurrence, current controls, detection, and the
   action priority or risk number.
4. Define actions for the highest priorities and record their
   implementation and re-rating.
5. Build the control plan: for each operation, the characteristics,
   specifications, measurement method, sample size and frequency,
   control method, and reaction plan.
6. Write work instructions for two operations with photos, step
   sequence, safety, and quality checks; have someone follow them.
7. Build the traceability matrix linking drawing characteristics to
   flow steps, PFMEA lines, control plan lines, and instructions.
8. Make a design change to one characteristic and propagate it through
   every document, recording the revision.

## Extension Ideas
- Add a measurement system analysis for one gauge.
- Add a PPAP-style submission package for the part.
- Add a layered process audit checklist.
- Create a visual standard for a cosmetic characteristic.

## Skills Demonstrated
- Process flow definition from drawing characteristics
- PFMEA methodology and action management
- Control plans and reaction plans
- Work instruction authoring and document linkage

## Industry Relevance

Automotive Suppliers, Aerospace Manufacturing, Medical Device Manufacturing. These sectors require PFMEAs and control plans for every part under their quality systems, and manufacturing engineers are hired on their ability to produce and maintain them. A linked documentation set with a propagated change is the exact daily work of the role.
