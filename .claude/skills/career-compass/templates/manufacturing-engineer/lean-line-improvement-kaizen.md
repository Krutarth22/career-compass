# Lean Line Improvement Kaizen

## Production Workflow Mirrored
1. Mapping a value stream and measuring the current state
2. Identifying waste with observation and time data
3. Running a kaizen event with the people who do the work
4. Implementing changes and measuring the future state
5. Sustaining with standard work and visual management

## What You'll Build
A documented improvement on a real repetitive process with at least
two people involved (a makerspace workflow, a small business's order
fulfilment, a campus kitchen line, a volunteer packing operation): a
current-state value stream map with measured cycle times, lead time,
and inventory, a waste analysis with a spaghetti diagram, a kaizen
event record with the team, implemented changes (layout, standard
work, visual controls, 5S), a future-state map with measured results,
and a sustainment plan.

## Student-Scope Notes
- The process must be real and the people who do it must participate;
  improving your own solo process is not enough.
- Measure with a stopwatch and observation sheets; video is helpful
  with consent.
- Aim for a measurable improvement in lead time, cycle time, or
  distance walked, however modest.

## Steps
1. Select the process and get agreement from the people involved and
   whoever owns it; define the scope and the metric.
2. Observe and measure the current state: process steps, cycle times,
   changeover, waiting, inventory between steps, and walking distance.
3. Draw the current-state value stream map and the spaghetti diagram,
   and compute lead time and value-added ratio.
4. Identify waste by category with the team and prioritize the causes.
5. Run a kaizen event: brainstorm, select changes, and implement them
   in a day or two (layout moves, point-of-use storage, standard work,
   visual signals, 5S).
6. Measure the future state with the same methods and draw the map.
7. Write standard work for the improved process and put visual
   management in place; check adherence after two weeks.
8. Write the kaizen report: before and after maps, data, the changes,
   the results, photos, and the sustainment plan, and present it to the
   process owner.

## Extension Ideas
- Introduce a pull system with kanban for a supply step.
- Run a changeover reduction study.
- Build a simulation of the line to test further changes.
- Run a second kaizen on the new bottleneck.

## Skills Demonstrated
- Value stream mapping and time measurement
- Waste identification and prioritization
- Facilitating team-based improvement
- Standard work and sustainment

## Industry Relevance

Automotive, Consumer Goods, Food Manufacturing, Logistics. Lean improvement is a universal expectation of manufacturing engineers in these sectors, and interviewers ask for a kaizen you led with numbers. A documented event on a real process with people and measured results is the story they want to hear.
