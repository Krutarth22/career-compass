# Multi-Omics Research Project Capstone

## Production Workflow Mirrored
1. Framing a biological question answerable with public data
2. Processing multiple data types through reproducible pipelines
3. Integrating results with sound statistics
4. Reviewing the analysis with a biologist and a statistician
5. Writing up as a manuscript-style report with shared code

## What You'll Build
A self-directed research project answering a biological question with
at least two omics data types from public sources (bulk and
single-cell expression, variants and expression, methylation and
expression): a pre-registered analysis plan, pipelines for each data
type, an integration analysis with appropriate statistics and multiple
testing control, figures of publication quality, a review by a
biologist and a statistician with responses, a manuscript-style
report, and a public code repository with the environment.

## Student-Scope Notes
- Reuse your pipelines; the capstone is the question, the integration,
  and the write-up.
- The reviewers can be mentors, lab members, or online community
  members who agree to read it.
- Write the analysis plan before touching the integrated data.

## Steps
1. Define the biological question, the datasets, and the hypotheses,
   and write the analysis plan with the planned tests and the
   multiple-testing strategy.
2. Process each data type through a reproducible pipeline with quality
   control reports.
3. Perform the primary analyses per data type as planned.
4. Integrate across data types (correlation of layers, joint modeling,
   or overlap tests with proper null models) and control multiple
   testing.
5. Produce the figures and tables to publication standard with
   consistent styling and complete legends.
6. Send the report to the reviewers, collect their comments, and revise
   with a written response to each.
7. Write the manuscript-style report: abstract, introduction, methods,
   results, discussion, limitations, and data and code availability.
8. Publish the repository with the environment, a run script, and the
   report, and present the project.

## Extension Ideas
- Submit the report as a preprint.
- Validate a finding on an independent dataset.
- Package a novel method from the project as a tool.
- Present the work at a lab meeting or a local meetup.

## Skills Demonstrated
- Framing and pre-registering a computational biology study
- Multi-omics processing and integration with rigorous statistics
- Responding to scientific review
- Manuscript-quality writing and fully reproducible code

## Industry Relevance

Pharmaceutical R&D, Biotech, Academic Research, Precision Medicine. Senior bioinformatics roles in these sectors require leading an analysis from question to write-up with statistical rigor, and interviews ask candidates to present exactly such a project. A reviewed, reproducible multi-omics study is the definitive bioinformatics portfolio.
