# Applied Epidemiology Program Capstone

## Production Workflow Mirrored
1. Running an epidemiology program for a condition in a jurisdiction
2. Combining surveillance, investigation, analytic study, and modeling
3. Producing outputs for officials, clinicians, and the public
4. Responding to a data request and a media inquiry accurately
5. Evaluating the program and recommending policy

## What You'll Build
An epidemiology program for one condition in a real jurisdiction using
public data and simulated events: a program plan with surveillance
objectives, the surveillance system and its routine reports, a
simulated outbreak response with an investigation report, an analytic
study of a risk factor with bias assessment, a transmission or trend
model supporting a policy question, spatial analysis with maps, a
public data request response and a media inquiry response, a program
evaluation, and a policy recommendation memo presented to a mock
health officer.

## Student-Scope Notes
- Reuse the systems and analyses from earlier templates on one
  condition and jurisdiction.
- Simulated events must be documented as simulations in every output.
- Mock stakeholders should include someone playing a health officer
  and a journalist.

## Steps
1. Write the program plan with objectives, data sources, outputs,
   audiences, and a calendar.
2. Operate the surveillance system for the condition and produce the
   routine reports over a simulated period.
3. Respond to a simulated outbreak with the full investigation and
   report.
4. Conduct the analytic study of a risk factor with STROBE reporting.
5. Build the model or trend analysis supporting a specific policy
   question and write the brief.
6. Produce spatial analyses with maps respecting suppression rules.
7. Respond to a data request and a media inquiry with accurate, clear,
   and appropriately caveated information.
8. Evaluate the program against its objectives, write the policy
   recommendation memo, and present it.

## Extension Ideas
- Add a health equity analysis and targeted recommendations.
- Build a public dashboard for the condition.
- Produce a peer-review-ready manuscript from the analytic study.
- Design an evaluation of the recommended policy.

## Skills Demonstrated
- Program-level epidemiology planning and operation
- Integrated surveillance, investigation, analysis, and modeling
- Multi-audience public health communication
- Program evaluation and policy recommendation

## Industry Relevance

Public Health Departments, National Health Agencies, International Organizations, Academic Public Health. Senior epidemiologist roles in these settings require running a program across all these functions and communicating to officials and the public, and interviews probe that breadth. A complete program capstone with outputs for every audience is the definitive applied epidemiology portfolio.
